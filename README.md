# EDA — Alojamientos Turísticos Airbnb

Exploratory data analysis of Airbnb listings and regional tourism data. Interactive dashboard built with Tableau.

---

## Descripción

Análisis exploratorio de datos de Airbnb (listings.csv) y datos autonómicos de turismo. Dashboard interactivo en Tableau con filtros dinámicos.

## Resultados y hallazgos clave

- Distribución de precios por tipo de alojamiento y zona geográfica
- Detección de outliers (>500€/noche) y análisis de valores extremos
- Dashboard Tableau con filtros dinámicos, tooltips y jerarquía visual
- **Hallazgo clave:** 'Entire home/apt' concentra mayor precio medio y varianza

## Archivos

Dataset: `listings.csv` (Airbnb), `alojamientos_turisticos.csv` (datos autonómicos)

## Tecnologías

`Python` `Tableau` `EDA` `pandas` `tourism`
